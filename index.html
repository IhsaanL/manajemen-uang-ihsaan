Belum backup

Cara memindahkan ke HP

  1. 1. Tekan Backup JSON di perangkat ini.
  2. 2. Kirim file ke HP lewat WhatsApp, email, atau kabel data.
  3. 3. Buka aplikasi di HP, pilih Restore JSON, lalu pilih file tersebut.

File backup memuat seluruh catatan dan pengaturan. Simpan di folder pribadi karena isinya sensitif.

Ruang privat

Catatanmu tidak dikirim ke mana pun.

Aplikasi berjalan tanpa server dan tanpa akun. Semua data disimpan di LocalStorage browser perangkat ini. Menghapus data browser dapat menghapus catatan, jadi lakukan backup rutin.

Zona hati-hati

Menghapus data transaksi dan langganan tidak bisa dibatalkan. Buat backup terlebih dahulu.
